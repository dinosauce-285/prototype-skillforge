HƯỚNG DẪN XEM DEMO SKILLFORGE
=============================

Dự án SkillForge cung cấp hai loại bản demo để kiểm tra giao diện:

1. DEMO MOBILE (Bản đồ các màn hình ứng dụng)
----------------------------------------------
- Vị trí: File **index.html** (nằm ở thư mục gốc).
- Cách xem: 
    - Nhấn đúp chuột để mở trực tiếp bằng trình duyệt.
    - Đây là trang tổng hợp chứa toàn bộ 19 màn hình mobile của Learner App và Payment App.
    - Nhấn vào nút "Open ↗" trên mỗi khung hình để xem chi tiết từng giao diện.

2. DEMO DESKTOP (Ứng dụng tương tác hoàn chỉnh)
----------------------------------------------
- Vị trí: Nằm trong thư mục **DEMO/**.
- Cách xem:
    - Đây là ứng dụng React dành cho desktop, yêu cầu môi trường NodeJS để khởi chạy.
    - Các bước thực hiện:
        1. Mở terminal tại thư mục `DEMO`.
        2. Chạy lệnh: `npm install` (nếu là lần đầu).
        3. Chạy lệnh: `npm run dev`.
        4. Truy cập địa chỉ `http://localhost:5173` trên trình duyệt.
- Lưu ý: Bản demo này tập trung vào trải nghiệm luồng người dùng trên nền tảng Web/Desktop.
