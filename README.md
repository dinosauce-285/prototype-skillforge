# 🚀 SkillForge Workspace | Project Demos

Welcome to the **SkillForge** prototype repository. This project contains two distinct demo environments to showcase both the mobile application screens and the interactive desktop web interface.

---

## 📱 Mobile Demo (Screen Catalog)
*A comprehensive collection of all mobile application interfaces.*

- **Location:** `index.html` (Project Root)
- **Status:** ✨ **Updated (Mobile Only)**
- **Total Screens:** 19 Frames

### 🛠 How to Use
1. Locate the `index.html` file in the root directory.
2. **Double-click** to open it in any modern web browser.
3. Browse through the **Learner App** and **Payment App** categories.
4. Click the **"Open ↗"** link on any card to view the high-fidelity interface in a new tab.

---

## 💻 Desktop Demo (Interactive Web App)
*A dynamic, interactive prototype built with React and Vite.*

- **Location:** `DEMO/` directory
- **Tech Stack:** React 19, Vite, Tailwind CSS
- **Features:** Navigation, interactive flows, and responsive design.

### 🚀 Getting Started
To run the interactive desktop environment locally, follow these steps:

1. **Open Terminal** and navigate to the demo folder:
   ```bash
   cd DEMO
   ```
2. **Install Dependencies** (required for the first time):
   ```bash
   npm install
   ```
3. **Start Development Server**:
   ```bash
   npm run dev
   ```
4. **Access the Demo**:
   Open [http://localhost:5173](http://localhost:5173) in your browser.
